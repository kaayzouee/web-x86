# Retro computer model

**Retro computer** by [Tobalation](https://sketchfab.com/3d-models/retro-computer-3a496376915846459d77fc14fdd6c1e0) (Dan Suwanseree), 2021.

License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

The source asset was supplied as `retro-computer.zip`. It contains `lowres computer.glb` and a texture. The website uses an optimized GLB with the original geometry and texture, gzip-compressed in `retro-computer.glb.gz`. Its material uses the texture for base color instead of full-strength emission, with a muted tint. The browser decompresses it before loading.

Mesh geometry and source texture are unchanged. The material was corrected to avoid an overexposed appearance. Attribution is displayed on the homepage.
