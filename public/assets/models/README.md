# Retro computer model

**Retro computer** by [Tobalation](https://sketchfab.com/3d-models/retro-computer-3a496376915846459d77fc14fdd6c1e0) (Dan Suwanseree), 2021.

License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

The source asset was supplied as `retro-computer.zip`. It contains `lowres computer.glb` and a texture. The website uses the original 33,640-byte GLB, gzip-compressed to `retro-computer.glb.gz` (8,838 bytes), and decompresses it in the browser before loading it.

No mesh or texture changes were made. Attribution is displayed on the homepage.
