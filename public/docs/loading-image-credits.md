# Loading collage — image sources

All three photos are public-domain works hosted by Wikimedia Commons. The loader uses Wikimedia thumbnails via remote URLs (no images vendored into this repository). Their display gets a teal monochrome CSS filter and is cropped inside rotating paper frames. No proprietary photo license applies.

- IBM 5150 system, 1981 — photographed by **Vintageibmmt**; public domain.
  https://commons.wikimedia.org/wiki/File:IBM_5150_PC.JPG
- Macintosh Plus — photographed by **Tmarki**; public domain.
  https://commons.wikimedia.org/wiki/File:Apple-Macintosh.jpg
- Commodore 64 — photographed by **Evan-Amos / Vanamo Media**; public domain.
  https://commons.wikimedia.org/wiki/File:Commodore-64-Computer-FL.jpg

Outside images are optional decoration; the loader still functions without them.
